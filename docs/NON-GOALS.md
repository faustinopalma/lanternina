# Non-goals

This document held the lines this project would not cross: what would never be built, and why. They were written before anybody had run an afternoon, and they are being written again from what the research finds rather than from what seemed obvious at the start.

**There is nothing here at the moment.** The compilation in `enciclopedia/` went through every way a thing to do can be put to somebody — including the ways that had been ruled out — and deliberately applied no rule while it worked, because a list filtered by the rules it is meant to inform is only a list of what had already been thought of. It is now complete, at 395 entries. What survives the review of it will be written here with the reasoning attached.

Until then this file makes no claim, and neither does `.github/copilot-instructions.md`. Code and tests elsewhere in the repository still enforce some of the old lines; where they do, the enforcement is the statement, and it stands or falls on its own until it is looked at.

What has not changed is what the project is for. Lanternina offers activities to an adolescent, with a parent steering, and it is built for adolescents without asking which ones. That sentence is a description, not a constraint, and it is the one thing the review starts from rather than reconsiders.
